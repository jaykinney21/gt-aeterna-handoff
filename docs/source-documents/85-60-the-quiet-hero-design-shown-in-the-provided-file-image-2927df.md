2. Engineering & Structural Architecture
This design features a highly functional, dual-component monumental architecture where a circular pedestal base acts as the secure primary foundation, supporting a heavily faceted, geometric vessel above.
Internal Volume Strategy: The continuous hollow chamber spans the calculated interior of the circular pedestal base (yielding substantial basal volume) and extends upward into the main vessel. It is engineered to comfortably hold a minimum of 200 cubic inches, making it suitable for one set of adult cremated remains.
Access Method: Secure access is bottom-loading, located on the underside of the circular pedestal base via a custom-cut rectangular metal access plate.
Hardware & Closure: The metal access plate sits flush within a precisely recessed lip. It is secured using four countersunk machine screws that thread directly into four pre-installed, heavy-duty brass inserts integrated into the structural walls, ensuring a secure, permanent seal and maximum pull-out strength.
3. Visual & Narrative Elements
The aesthetic is a powerful, architectural tribute to blue-collar workers and enduring strength, utilizing rough faux-stone textures contrasted by rich metallic bronze.
The Central Canvas (The Vessel): The main upper body features a complex, asymmetrical faceted geometry designed to replicate carved stone or fractured concrete. Protruding from the lower structural fissures is a sharp, geometric wedge finished in metallic bronze, symbolizing foundational strength and resilience.
The Lid: The vessel is capped with a flat-top circular lid finished entirely in metallic bronze, featuring a prominent, raised 8-point compass star motif.
The Base Canvas: The wide, circular pedestal base provides a heavy, stabilizing foundation. It is finished in a subtle, textured grey pattern that complements the concrete aesthetic of the main vessel. The base is formally framed at both the top and bottom edges by smooth bronze trim rings. A single, raised red heart sits on the front face of the base.
