Technical Design Specification: "Eternal Valor" Legacy Ur

1. Dimensional & Volumetric Data
Overall Dimensions (Urn with Base): 10.75 in (273 mm) Height x 7.75 in (197 mm) Diameter.
Urn Dimensions (Vessel): 8.0 in (203 mm) Height x 7.0 in (178 mm) Max Diameter.
Base Dimensions (External): 2.75 in (70 mm) Height x 7.75 in (197 mm) Diameter.
Base Internal Depth: 2.50 in (64 mm).
Storage Capacity: Holds 200+ cubic inches (Usable volume: 203 cubic inches), designed for one set of adult cremated remains.

2. Engineering & Structural Architecture
Internal Storage: The primary storage chamber is housed securely within the circular pedestal base.
Access Method: Features secure, dignified, bottom-loading access through the underside of the pedestal base.
Closure Hardware System: Utilizes a custom-cut, rectangular metal base plate (brushed stainless steel or aluminum) that sits flush within a recessed lip.
Security Anchors: The access plate is secured using four countersunk machine screws threaded into pre-modeled brass inserts embedded in the 3D-printed walls.

3. Visual & Narrative Elements
Vessel Aesthetic: The upper vessel features a deep, rich red finish with gold-colored emblems, including a military-themed crest on the front and a memorial scene on the back featuring a helmet, rifle, and boots silhouette.
Base & Lid Details: The pedestal base is finished with gold trim, featuring text such as "ETERNAL VALOR" and "HONOR - COURAGE - COMMITMENT". The lid is a simple, matching domed design with gold trim.
Narrative Text: The front base bears the text "ETERNAL VALOR". The back of the vessel features the phrase "ALWAYS FAITHFUL".

4. Material & Finishing Protocols
Core Construction: Fabricated using durable 3D-printed resin designed to look like wood and metal.
Finish Details: Features hand-painted details with gold accents and emblems.
Manufacturing Note: Dimensions are approximate, as minor variations may occur during the 3D printing and finishing processes.

5. Typography & Personalization
Personalization (Base Rear): The rear face of the pedestal base includes a designated area for bespoke text, formatted for the name, birth/death dates, and a sentiment such as "Forever In Our Hearts".
