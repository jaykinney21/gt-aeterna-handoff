Technical Design Specification: "Lotus of Purity Urn"
1. Dimensional & Volumetric Data
Overall Dimensions: 11.75 in (298.5 mm) Height x 7.75 in (196.9 mm) Overall Diameter.
Urn (Vase) Dimensions: 8.00 in (203.2 mm) Height x 7.00 in (177.8 mm) Diameter.
Base Dimensions: 3.75 in (95.3 mm) Height x 7.75 in (196.9 mm) Diameter.
Storage Capacity: 200+ cubic inches, suitable for one set of adult cremated remains.
2. Engineering & Structural Architecture
Access Method: Bottom-loading access through the underside of the circular pedestal base.
Closure Hardware System: Utilizes a custom-cut, rectangular metal base plate (brushed stainless steel or aluminum) that sits flush within a recessed lip.
Security Anchors: The access plate is secured using four countersunk machine screws threaded into pre-modeled brass inserts.
3. Visual & Narrative Elements
Vessel Aesthetic: Features a green finish with a sculptural gold lotus flower motif on the front, back, and lid.
Narrative Themes: Inspired by the lotus as a symbol of purity, enlightenment, and spiritual awakening.
Design Philosophy: "Beautiful outside. Sacred within".
4. Material & Finishing Protocols
Core Construction: Expertly designed with high-quality 3D-printed materials.
Sustainability: Earth-conscious, made with sustainable materials and a deep respect for all life.
Finish Details: Features lasting finishes.
5. Typography & Personalization
Personalization (Base Rear): The rear face of the pedestal base includes a designated nameplate area for bespoke text, formatted for the full name, sunrise date, and sunset date, preceded by "IN LOVING MEMORY OF".
