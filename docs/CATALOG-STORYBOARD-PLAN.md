## Production sequence and completion checks

1. **Completed now:** identify actual prompt sources, inventory all Section 3 entries, draft six source-linked storyboard cards, and record mismatches.
2. Choose the first visual track and pilot lineup. Recommended initial reference set: six cards above; DOC NOTES-only new concepts follow as a distinct set. A smaller first review can start with one reference design and one exact DOC NOTES concept to establish fidelity/style.
3. Review embedded reference images at full size and select one authoritative reference per card. Text extraction alone is not visual validation. Resolve competing versions and attach references to prompt records.
4. Assemble six hero prompt jobs and one accessory concept job at most for the first pass; log template, adaptations, reference image, generator, settings and output filename. Paid generation limits must be explicit before spending.
5. Generate the selected pass, then review silhouette, color, base, text handling and reference fidelity. Reject attractive but materially different renderings. Add detail views after the first pass is coherent.
6. Lay out an editable catalog and review PDF. Keep names, captions, claims and text in editable fields. Use “Design concept — not yet manufactured” on unbuilt items. Existing STL status does not establish manufacturability.
7. Publish no price, availability, capacity, niche-fit, permanence, outdoor-durability, seal or live digital-service claim until supported. Keep proposed bundle quantities separate from priced, purchasable bundles.

Suggested production naming: `P01_HERO_CONCEPT_REV-A.png`, `P01_DETAIL_CONCEPT_REV-A.png`. These are editorial asset identifiers, not replacement SKUs. Preserve existing legacy SKUs as source identifiers. Section 6's new architecture is `[CATEGORY]-[DESIGN]-[FORM/SIZE]-[FINISH]-[ITEM_TYPE]`; do not invent final SKU segments to fill gaps. Its CAD naming rule must not be used to label imagery as CAD.

Completion for the current preparation stage is this reviewable document. The later visual deliverable is a coherent image series plus editable catalog and review PDF. Specialist responsibilities: source/editorial reconciliation, reference-driven image production, layout, and final visual/factual review; these roles need not become four separate paid tools.
