# Every Step Legacy — revision 7 brief

> Public handoff copy. Dated work status is historical; see the repository README for the newly authorized public download handoff and current instructions. Private source access and machine-specific account details are omitted.

September 22, 2026. The user authorized implementing the fourteen observations from the v6 reference comparison. V6 is preserved.

## Accepted visual corrections

1. Fuller, softer teardrop cap; avoid a sharp leaf shape.
2. More substantial bronze cap border.
3. Tighter, upright black fold beneath the cap.
4. Smaller, shallower shoulder reveal.
5. Broader upper bronze sweep and more gradual, narrower lower taper.
6. Stitching begins closer to the cap and has a longer visible run.
7. Stronger football-style cross stitches with less crowded spacing.
8. Irregular rounded core texture with restrained highlights rather than a fabric-like appearance.
9. Controlled visible fine grain on the writing panel.
10. Larger inscription, moved left toward the panel center.
11. Larger heart, closer to the words.
12. Visually shorter base with heavier bronze outer trim and less mechanically uniform texture.
13. Warmer brown bronze with a less polished finish.
14. Clarify the plaque difference between the main reference front and the separate base specification.

## Plaque handling

The specified plaque stays in the editable working model. A separate actual Blender render hides it to compare the main source silhouette fairly. This is explicitly labeled; it is not an unannounced deletion from the design.

## Review and limits

`output/cad/review-v7/index.html` presents source comparisons and rendered views. `EVERY-STEP-V7-INDEPENDENT-REVIEW.md` records the actual visual findings. The native model and repeatable script are in `output/cad/refinement-v7/`.

These are appearance changes. Reduced visual base height and other provisional proportions must not be mistaken for validated source dimensions, capacity or production CAD. Cavity, walls, closure and physical finish remain separate engineering work.
