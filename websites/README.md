# Website source snapshots

Recovered project source, preserved for handoff. These are historical snapshots, not a newly deployed site or a verified production checkout. Product copy, prices, claims and contact placeholders require review before launch.

- `aeterna/`: static urn-store concept. Open `index.html` for a basic preview; serve the directory locally for the Three.js customization page. External fonts and Three.js load from their original public providers.
- `graceful-tributes/`: Next.js memorial-service landing page and supporting API source. Existing package manifests and lockfile are included. Install its declared dependencies in that directory and use `npm run dev`. Credentials and live integration configuration are not included. The former unrelated platform portal default was removed; supply your own URL through the documented environment variable. Placeholder phone numbers are retained as placeholders.

No fitness project, unrelated server/operations folder, deployment credentials, private platform links or historic Git data is included. Source attribution comments are preserved. This transfer checks file completeness and public-sharing suitability; it does not verify live integrations or rebuild these historical sites.
