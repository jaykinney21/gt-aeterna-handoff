# Design references

`source-documents/<ID>/imageN.png` preserves all 159 images extracted from the numbered project Word documents. The IDs match [the source-text index](../docs/source-documents/INDEX.md). Sources 36–40 are the older five-design baseline, sources 46–50 are historical updated briefs, and source 63 is Every Step Legacy.

`legacy-collections/` contains the six embedded images from recovered user project collection pages. These are reference artwork, not photographs of manufactured products. Refer to `manifest.json` for exact image hashes.
