# AETERNA / Graceful Tributes project handoff

Public working archive for the urn, keepsake, catalog and memorial-service project. Prepared October 4, 2026 for continuing the work on another Mac with Codex.

## Start here

1. Read the [current redesign and vendor triage](docs/URN-REDESIGN-AND-VENDOR-TRIAGE-2026-10-04.md).
2. Review the [five-design specification matrix](docs/specifications/ARCHITECTURE-AND-SPEC-MATRIX.md) and [new-model intake checklist](docs/research/new-stl-intake-and-specification-checklist-2026-10-04.md).
3. Browse the [source notes, requirements and prompts](docs/source-documents/INDEX.md).
4. Follow [DOWNLOADS.md](DOWNLOADS.md) to get the catalog, CAD previews and larger model files.

This public transfer supersedes earlier notes saying the work is local-only or that a private repository was proposed. Historical documents describe their original date and status. They do not change the current engineering or vendor decisions.

## Current position

Mom is creating revised artwork in Tripo. Those new exports have not yet been received here. The original five design families and the Every Step Legacy Blender iterations are historical working material. No physical urn has been manufactured or validated through this work, and no model is designated production-ready.

The larger display design places ashes in an engineered base. The compact design targets a whole assembly at most 10 inches high and may use a hollow upper vessel. Capacity, access, closure, stability, finish and the exact cemetery niche dimensions still need verification. The latest triage explains the conflicts and next steps. Existing vendor estimates concern older geometry; new revised pricing waits for the new files and specifications.

## Work on Mom's Mac

Download the repository ZIP from GitHub using **Code → Download ZIP**, unzip it, then open that folder as a project in Codex. Download the model bundles from **Releases** when needed. No shared ChatGPT login is required to read or download this public repository.

Ask Codex: “Read AGENTS.md, README.md and the current October 4 redesign triage. Inventory my incoming Tripo files against the five working specifications. Show visual and engineering issues before changing files or preparing a manufacturing release.”

For ongoing collaboration, a Git clone supports branches and pull requests; a downloaded ZIP is a convenient starting copy. See [CONTRIBUTING.md](CONTRIBUTING.md) for how to record progress and exchange revisions. A shared Space can hold decisions and progress, while this repository holds the downloadable project files.

## Public archive boundaries

Private correspondence and email headers, personal contact/shipping information, credentials, account/session data, unrelated company projects and the original local Git history are excluded. Supplier findings are retained as project summaries. Local-only paths and private cloud links have been removed or replaced with portable references.

See [NOTICE.md](NOTICE.md) for reuse and attribution. Public availability is not a manufacturing approval or a blanket license for third-party designs, brands or likenesses.
