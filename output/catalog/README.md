# Catalogue concept pilot

Open [the editable catalogue](index.html), [the earlier storyboard](index-v1.html), or [the eight-page review PDF](catalog-review-v2.pdf). Keep the `assets/` folder beside the HTML files when copying this catalogue.

The folder preserves all sixteen source and generated images, exact generation prompts, the original and corrected concept revisions, and manifests. The catalogue covers seven vessel directions and one Every Step accessory study. The full source inventory is broader than this pilot.

These are concept illustrations and editorial review files, with no approved price, availability, capacity, fit, seal, materials, or manufacturing claims. Older captions record the state of the pilot when it was produced; the current project direction is in the repository's latest October 4 triage.

Titles, captions, and notes in the HTML are editable. Save an edited HTML copy into this directory to retain image links. HTML edits do not automatically update the supplied PDF. `build_pilot.py` rebuilds the HTML, manifest, and PDF from its source rows; it requires Python 3, Pillow, and ReportLab.
